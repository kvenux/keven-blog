# 配图提示词清单

7 张白板风格信息图，对应文章的 7 个关键概念点。每段 prompt 可直接喂给 AI 绘图工具（Midjourney / DALL-E / 即梦 / 通义万相等）。

## 总览

| # | 位置 | 主题 | 布局 |
|---|---|---|---|
| 1 | 开头 hero | AI 时代能力位次重排（旧 vs 新） | 左右对比 |
| 2 | 第一章末 | 大脑是网 + 元认知是反向照自己 | 上下两层 |
| 3 | 第二章 | 学习两种方式：塞节点 vs 织线（transformer 例子） | 左右对比 |
| 4 | 第三章 | 定义问题三层 + 爱因斯坦 7 年专利长出相对论 | 左金字塔 + 右时间线 |
| 5 | 第五章开篇 | 两次生两次死时间轴 + 两种人生路径 | 横向时间轴 |
| 6 | 第六章 | 三层脑 + Kahneman 双系统 + 元认知是叫醒动作 | 左中右三栏 |
| 7 | 结尾 | 哲学三问 = AI 时代能力定价表 | 左石碑 + 右价目表 |


## 使用说明

1. 选一个 AI 绘图工具（推荐顺序：即梦 / 通义万相 / GPT-4o image generation / Midjourney v6+，中文白板风格效果较好）
2. 整段 prompt 复制粘贴进去（不需要拆分）
3. 生成后如果某些细节没出来（手写体不清、火柴人比例怪、文字模糊），可以局部调整 prompt 强调那部分，或者多 reroll 几次
4. 出图后保存到 `articles/metacognition-ai-era/assets/`，命名建议 `01-hero-pricing-rerank.png`、`02-network-mirror.png` 这样按顺序
5. 然后在 `source.md` 对应章节插入：`![描述](assets/01-hero-pricing-rerank.png)`
