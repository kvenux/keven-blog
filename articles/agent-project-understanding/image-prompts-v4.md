# 配图风格试稿 v4

用户指定 whiteboard 技能手绘风：细头白板笔、细手写字体、丰富的节点关系，拒绝卡通和论文图表。先生成一张校准风格。

生成一张“专家白板教学”风格的手绘信息图，主题：Agent与人类程序员怎样理解代码仓。横版16:9，完全不透明的纯白白板背景。必须是真实细头马克笔/白板笔手绘，像技术专家亲自在白板上边讲边画，不是论文排版、不是矢量流程图、不是杂志艺术插画、不是PPT。自然有轻微弯曲的不规则线条，清晰纤细的手写中文字，标题也不要粗重。蓝黑色为主，绿色标经验，红色圈重点，极少浅黄色手工涂色。不要卡通图标、机器人、书本、放大镜、3D、便签纸、爆炸形标注、粗彩色圆角框。内容要丰富，但依靠逻辑细节而非装饰。

**视觉元素：** 左右两个不完全对称的手绘知识网络，上方共同问题，下方对照总结。线条笔迹自然，允许短批注、下划线、圈重点。不用表格、不用网格、不用整齐泳道。主区域4个，35%留白，字不重叠。

**画面顶部：** 手写大标题“Agent 和人，怎样读懂同一个项目？”，细红色随手下划线。标题下画一个轻微不规则的问题框，写“登录后，缓存会区分用户吗？”，细箭头分向两侧，线上标“同一个问题”。

**画面左侧：** 主标签“Agent：现场构建”。上方一个细线椭圆“通用编程先验”，内部写“缓存 / 认证 / 请求顺序”；下面画真实手绘的小型文件树和短代码行，不要彩色文件图标，旁边字“rg 找入口 → read 读实现”。树的分支接出三组小节点：“缓存键”“身份读取”“检查顺序”，使用蓝色细线连接，每组还画2—3个未标注的小圆点表示源码事实。用不规则虚线圈住这片关系网，旁注“本次上下文”。圈外下方以一条断续线指向“下次任务”，线上写“需带入历史认识”。这不是表示没有理解，而是表示当次上下文与跨会话积累不同。

**画面右侧：** 主标签“人类：带着经验核对”。上方一个更丰富的绿色手绘节点网络，中央写“项目级心智模型”；四周节点“模块职责”“执行顺序”“历史故障”“设计理由”，再增加8个没有文字的小节点和若干不同强弱的细线，体现已积累关系。其中登录、会话、缓存三个有文字节点用红圈和局部高亮线表示本题激活。网络下方写“缩小范围 → 核对当前代码”，再用自然弧形绿色回流箭头指回网络，箭头旁写“新发现，修正旧认识”。右侧边缘一个短手写批注“经验进入下一次判断”，用细指示线连回网络。不画脑轮廓。

**画面中下部：** 一条细黑色横向大括号连两侧，写“共同点：用当前代码核验”。下方左边写“强先验 + 大上下文”，右边写“项目经验 + 持续学习”。留出间距，不用背景横条。

**画面右下角：** 一句手写圈重点“让查明的关系留下来”，用细红椭圆圈住，不要便签或卡通。短虚线指向左侧跨会话连接处。

**文字：** 全部是清楚的手写细字，中文主导。底部一句“知识工具：让 Agent 少重建，让人持续理解”。不要刻板字体，不要数学公式，不要额外长段落。

**图上文字白名单：** Agent 和人，怎样读懂同一个项目？；登录后，缓存会区分用户吗？；同一个问题；Agent：现场构建；通用编程先验；缓存 / 认证 / 请求顺序；rg 找入口 → read 读实现；缓存键；身份读取；检查顺序；本次上下文；下次任务；需带入历史认识；人类：带着经验核对；项目级心智模型；模块职责；执行顺序；历史故障；设计理由；登录；会话；缓存；缩小范围 → 核对当前代码；新发现，修正旧认识；经验进入下一次判断；共同点：用当前代码核验；强先验 + 大上下文；项目经验 + 持续学习；让查明的关系留下来；知识工具：让 Agent 少重建，让人持续理解。

**内容结构：** 专家白板的自然手绘讲解感，知识网络和回流机制为主体，细笔、细字、具体关系丰富，不要大图标，不要稀疏简笔画，不要论文图表。背景填满白色且所有像素不透明。
