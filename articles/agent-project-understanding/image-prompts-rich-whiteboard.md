# 白板手绘增强版

用户反馈：细笔版本太素。保持细字和机制内容，增加彩色马克笔涂色、排线、局部小线稿、主次箭头层次。内置 image_gen 对现有四图逐张编辑。

+编辑这张白板图，保留全部准确文字、信息结构、节点、箭头方向及16:9比例，做一次明显的“手绘白板视觉丰富化”。现在这张太素、像单色细笔板书，需要专业sketchnote白板的手绘层次和视觉吸引力。

具体改法：
1. 仍用清晰纤细的中文手写字，不加粗成儿童海报字。标题保留自然手写，只给标题背后加一条浅金色手涂荧光笔底纹。
2. 给主要知识节点增加浅蓝、薄荷绿、浅金黄的不均匀手工涂色，色块有叠笔痕迹、排线和略微出边的手绘质感。全图约20%-30%区域着色，保留白底。不能只是统一淡色填充，必须看得出马克笔横向笔触。
3. 主路径箭头用双线空心手绘箭头或轻微粗细变化的彩色弧箭头，辅助路径继续细线，文字不变。为重点圈注加入红色二次描线、小短划和有节制的手画波浪下划线。
4. 在现有留白处加3-4个与本图语义直接有关的小幅手绘线稿，如代码文件叠页、终端小窗、分叉路径、互相连接的节点或核对清单。这些线稿要有精细笔触和少量阴影排线，属于成人技术笔记，不是大号卡通图标。大小控制在主体节点的1/3以内。不能抢占正文。
5. 网络区域的连线与节点要更有视觉层次：弱关系细灰绿，主关系蓝绿，当前激活点少量红黄强调。节点之间可以有轻微不规则、有机的布局，不能画成论文式匀称网格。
6. 重点结论用不规则的细线手绘包围和浅黄涂色强调，不能画实物便签。画面自然生动，像专家用几支彩色白板笔认真讲解后的白板。
禁止：改变文字、删减要点、加入新事实或数字、增加人物机器人、大脑、幼儿卡通、3D立体阴影、论文表格、PPT模版、整张铺色、粗字体。背景保持完全不透明纯白。必须显著增加色彩与手绘装饰层次，同时保留细字与全部机制信息。
