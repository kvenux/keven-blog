# 配图风格试稿 v3

用户反馈：v1过于卡通、要素少且字体粗；v2过于论文。改为细笔手绘知识地图与编辑插画，先验证一张封面。

为中文技术博客制作一张有审美、有信息量的横版16:9配图。风格是杂志编辑插画与细笔手绘知识地图的结合，不是论文图表，不是PPT，不是卡通科普。背景是完全不透明的温白纸（接近#FAFAF7），极轻纸感。细钢笔轮廓，克制的蓝灰、鼠尾草绿与少量朱红，水彩薄染，大量精细但不喧宾夺主的线条。标题为纤细自然的中文手写字，正文字细而清楚。不要粗黑字体、粗箭头、圆角卡片、表格、泳道、编号列表、卡通物件、机器人、大脑、放大镜、书本、便签、3D和投影。

主题：Agent与人类程序员理解代码仓的差异。用两幅占据主体的“知识地形”来讲故事，整个画面自然连续，禁止把内容关进框里。
画面上部留出漂亮的题头，写“同一个项目，两种理解方式”。标题下只一行小副标题：“通用先验，项目经验”。

左侧是蓝灰色的广阔知识星图：60个大小不一的细小节点及许多纤细连线，像一张精密但自然的知识地图。散布5个清晰短标签：“缓存”“认证”“异步”“数据访问”“通用先验”。其中一小片节点被精细的朱红虚线弧圈选出，像从广阔地图中取样。圈选区域沿几条优雅曲线下行，汇成下方一个只有7个节点的紧密局部网络，其中3个节点标“入口”“规则”“证据”。旁边两条小字：“围绕问题检索”“在当前上下文中连接”。左上区域主标签“Agent”。
注意：左侧大网代表通用先验，小网代表本次任务理解，不要把所有代码仓画成可以直接访问的资料库。

右侧是鼠尾草绿色的项目关系网：节点密度不低，40个左右，层叠但清晰。以树木生长脉络般的有机形态排布线条，但不要实际画树或树叶。中间一条主路径由左下向右上延伸，旧连接呈浅灰绿，新连接呈深绿和少量朱红。5个清晰节点标签：“模块职责”“执行顺序”“历史故障”“设计理由”“项目经验”。在网的下缘，用一条细长绿色回弧重新接回网络的上方，标“核对代码，更新认识”。右上主标签“人类程序员”。下方小字：“经验进入下一次判断”。

左右网络之间保留呼吸空间，只以一句小字连接：“都要用当前代码核验”。不要垂直分隔线。
画面下沿用两个短句形成节奏，左“广泛先验 → 现场建立理解”，右“项目经验 → 持续修正积累”。最底部只一句轻细文本：“Agent 的跨会话积累，需要保留并带入历史认识”。

丰富来自网络结构、线条层次、信息关联与精致构图，而非图标和大块文字。画面利用率75%左右，25%安静留白。所有文字只用上述指定文字，不增加解释段落，不画夸张符号。确保中文准确，背景全部不透明。
