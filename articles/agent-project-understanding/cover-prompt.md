中央靠下的位置：一个小巧的手绘文件树/代码仓，只有一个根节点和几个文件线稿，标“同一个代码仓”。代码仓到左右知识网络各有一条自然的细连接曲线，没有箭头，也不写额外标签，表示两者都在理解它。中央不能抢过左右主体。
