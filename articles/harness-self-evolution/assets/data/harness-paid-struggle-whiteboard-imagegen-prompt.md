# Harness paid-struggle whiteboard prompt

Use case: infographic-diagram

Asset type: article opening mechanism diagram, landscape 16:9 expert whiteboard.

Primary request: Show that Lean was not produced by one obvious pruning decision. The visual center must be the expensive self-optimization struggle: real trajectories create competing Harness candidates; every candidate consumes paid model runs; several plausible optimizations are rejected; the surviving evidence changes the next generation.

Composition: a wide left-to-right evolutionary landscape with three major regions. Left 22% is the starting Standard workflow. Center 53% is a branching paid experiment arena and must be the visual focus. Right 25% is the selected Lean workflow. Use a thick main arrow from left to right, with rejected branches visibly falling downward into a red `Token 学费` pile, while accepted branches rejoin the main evolutionary path.

Left region, orange/red: heading `起点 Standard`. Show a compact stack of external artifacts rather than every large workflow box: `proposal / spec / design / tasks / validation / review`. Beside it show `11.49M Token / run` and `18/24 完成交付`. Feed its session traces into the center with one combined arrow label `真实 trajectory → 付费自优化战场`.

Center region, dominant: visually emphasize the paid experiment arena. Draw `Trajectory Reviewer` reading a pile of success and failure session strips, then `Evolver Agent` creating candidate branches. Four candidate experiment cards:

1. Green/yellow card `Light｜8.57M｜保留`.
2. Red rejected card `多会话拆分｜novel +31.3%｜calls +72.2%｜得分 −3｜拒绝`.
3. Red rejected card `持续 review｜发现缺口｜未交付｜拒绝`.
4. Green accepted card `高密度 delta-spec｜得分 +13.83｜进入下一代`.

Each branch must have a small burning Token receipt/meter icon. Rejected branches fall into a visible pile labeled `Token 学费`. Near the pile write `错误方向也真实付费`. Draw an outer-loop arrow from `回放 + 测试 + 盲评` back to the experiment arena. The center should feel like struggle, selection and accumulated evidence, not a clean linear plan.

Right region, blue/green: heading `收敛 Lean`. Show only the final cross-session interface in one clear chain labeled `Operator ↔ 规格 Agent → delta-spec → 实现 + 验证 → 交付`. Beside it show one ledger labeled `4.03M / run｜92.19 分｜24/24`.

Style/medium: authentic expert classroom whiteboard, off-white textured board, uneven black marker lines, compact annotated cards and session-strip icons. Orange/red for costly or rejected paths; blue/green for accepted paths. High information density similar to a serious engineering postmortem whiteboard, but one obvious visual focus in the center. No polished corporate poster, no 3D, no decorative gradients.
